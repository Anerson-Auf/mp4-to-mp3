# MP4 to MP3

Небольшая консольная утилита на Rust для конвертации аудио из MP4 в MP3 с поддержкой контекстного меню (ПКМ).

Для декодирования аудио используется Symphonia, для кодирования в MP3 — shine-rs.

## Возможности

- Конвертация аудио из MP4 в MP3.
- Отображение прогресса конвертации в терминале.
- Интеграция с контекстным меню Проводника Windows.
- Автоматическое определение имени выходного файла.

## Использование

### Конвертация файла

```bash
mp4-to-mp3 input.mp4
```

Выходной файл будет создан рядом с исходным:

```text
input.mp3
```

### Указание выходного файла

```bash
mp4-to-mp3 input.mp4 output.mp3
```

### Интеграция с Проводником Windows

Добавить пункт конвертации в контекстное меню:

```bash
mp4-to-mp3 install
```

После установки при нажатии правой кнопкой мыши на MP4-файл появится пункт "To MP3".

Удалить пункт из контекстного меню:

```bash
mp4-to-mp3 uninstall
```

## Сборка

```bash
cargo build --release
```

## Используемые библиотеки

- Symphonia - декодирование аудио.
- shine-rs - кодирование аудио в MP3.
- indicatif - отображение прогресса в терминале.
- winreg - работа с реестром Windows.
